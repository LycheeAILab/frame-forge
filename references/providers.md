# 内置生图

## 用户内置工具

查看当前工具列表和 schema，使用实际可调用的内置生图工具。无需配置 API key，不读取或导出 Codex 登录凭据。工具未暴露模型选择时不能硬填 gpt-image-2，也不能声称已确认其底层模型。

按工具文档传递真实参考图片。本地图片先检视再传图；本宿主可用 referenced_image_paths 或 num_last_images_to_include，不能同时传两者，其他宿主按实际 schema 映射。纯文字生图不传示例图。

超时、限流、任务进行中或结果未知时保留原任务，等待或查询结果，不重复提交。

内置工具不可用时，明确说明当前无法生成，并交付完整提示词供用户后续使用。不得把提示词或已有示例描述为新生成图片。
